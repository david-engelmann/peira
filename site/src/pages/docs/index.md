# Docs

Start with Quickstart to run your first scored run, then Interpreting
results to read the leaderboard like a regular. Adapter setup covers
every adapter family, and the FAQ answers the questions everyone asks.

- [Quickstart](/docs/quickstart). Install to first scored run in minutes.
- [Interpreting results](/docs/interpreting-results). How to read every
  view on this site and what the numbers do and do not mean.
- [Adapter setup](/docs/adapter-setup). One-time setup for local
  guardrails, hosted LLM baselines, and local rule-based baselines.
- [FAQ](/docs/faq). Short answers on suites, budgets, and primitives.

The [Methodology](/methodology) page describes how every metric is
computed, from the same definitions the pipeline implements.
