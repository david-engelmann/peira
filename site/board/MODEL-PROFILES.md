# Board model profiles

The explorer looks up the exact `adapter_name` and `adapter_version` in each published row. To review a new pair, start with its `provenance.adapter_spec` and `adapter_revision`, then check the adapter docs and the publisher’s checkpoint record. An unreviewed pair displays unknown values and is outside the frontier cohort. [Published payload](data/payload.json), [adapter documentation](../../docs/Adapters.md)

- **Model type** describes the measured checkpoint’s purpose. Specialist decision models are built or tuned for typed decisions. General-purpose models cover a broader range of tasks. Safety and prompt-injection classifiers are guards. GPT-6 Luna is general-purpose on both APIs, which pin the same model ID. SemIf wraps unmodified Qwen3.5-4B weights, so its measured model is general-purpose. [GPT-6 Luna](../../docs/Adapters.md#gpt-6-luna-openai), [OpenAI Decisions](../../docs/Adapters.md#openai-decisions), [SemIf](../../docs/Adapters.md#semif), [Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B)
- **Serving** describes where Peira ran inference. Local includes in-process models, a local subprocess, and self-hosted servers such as Kev, Von, and Strands Decider. Hosted means Peira used a provider service. Cloudflare Clef and Perplexity Decider are hosted in the measured runs and have downloadable checkpoints. [Kev](../../docs/Adapters.md#kev), [Von](../../docs/Adapters.md#von), [Strands Decider](../../docs/Adapters.md#strands-decider), [Clef release](https://blog.cloudflare.com/clef-faster-cheaper-multimodal/), [Perplexity checkpoints](https://huggingface.co/perplexity-ai/models)
- **Weights** describes how the measured checkpoint is distributed. Open identifies documented public downloads under the model’s published license. Gated indicates a documented access or license gate, as for Llama Prompt Guard 2. Unreleased requires explicit evidence, as for Microsoft Decision 1. Hosted access alone leaves weights unknown. The old Perplexity Decider v1.1 API alias can serve v1.2. Both checkpoints have published weights, and the alias remains the reported run identity. [Meta Llama Prompt Guard 2](https://huggingface.co/meta-llama/Llama-Prompt-Guard-2-86M), [Microsoft Decision 1](../../docs/Adapters.md#openrouter-decisions), [Perplexity adapter notes](../../docs/Adapters.md#pplx-decider-v12-and-pplx-decider-flash-v12-perplexity)
- **Frontier baseline** is an editorial cohort for comparing the named general-purpose baseline models from OpenAI, Google, Anthropic, Moonshot, xAI, DeepSeek, Zhipu, and MiniMax in the adapter docs. The cohort includes both measured wires for GPT-6 Luna. Gateway pilot models, Mercury 3, and SemIf sit outside this scope. Membership is independent of rank, admission status, score, price, and the chart’s cost and attack success frontier. [Structured-output LLM baselines](../../docs/Adapters.md#structured-output-llm-baselines), [gateway pilot set](../../docs/Adapters.md#cheap-model-pilot-set)

Additional publisher records support the open weights assigned to hosted general-purpose rows. [DeepSeek V4.1 Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash), [MiniMax M3](https://huggingface.co/MiniMaxAI/MiniMax-M3), [MiniMax M3.1 Flash](https://huggingface.co/MiniMaxAI/MiniMax-M3.1-Flash), [Qwen3 235B 2507](https://huggingface.co/Qwen/Qwen3-235B-A22B-Instruct-2507), [inclusionAI Ling 3.0 Flash](https://huggingface.co/inclusionAI/Ling-3.0-flash), [Ling 3.0 Flash VL](https://huggingface.co/inclusionAI/Ling-3.0-flash-VL), [Ling 3.1 Flash](https://huggingface.co/inclusionAI/Ling-3.1-flash)

Publisher records also document public downloads for Shieldstral and Protect AI’s prompt-injection guard. [Mistral Shieldstral](https://huggingface.co/mistralai/Shieldstral-1.0-3B), [Protect AI’s injection detector](https://huggingface.co/protectai/deberta-v3-base-prompt-injection-v2)
