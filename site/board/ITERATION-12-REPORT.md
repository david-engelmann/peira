# Iteration 12

Iteration 12 introduced detailed per-run records and a common explorer for rankings, costs and attack families. The branch records the layout and behavior of that prototype. The current board uses a themed study layout with linked charts and permanent model addresses.

The original implementation is preserved on the [iteration 12 branch](https://github.com/david-engelmann/peira/tree/handover/iteration-12). Current chart conventions, project context and model classification evidence are documented in the [design guide](DESIGN.md), [board product guide](PRODUCT.md) and [model profiles](MODEL-PROFILES.md).
