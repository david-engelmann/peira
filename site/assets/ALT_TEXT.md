# Alt text for site image assets

Every image used by the peira site has a text alternative. Images with
a dedicated `.alt.txt` sidecar point at it. Images without one are
described in full below.

## og-leaderboard.svg and og-leaderboard.png

Found in `site/assets/og/`

Alt text lives in `og-leaderboard.alt.txt`, generated by
`site/scripts/render_og.py` from the same site-data JSON the image is
drawn from. When the data is mock, both the image and the alt text say
so.

## fallbacks/install.svg

Found in `site/assets/fallbacks/`

Alt text lives in `install.alt.txt`. An illustrative terminal mock of
the install step. A dark terminal window shows `pip install -e .`
followed by abbreviated installer lines ending in a success line. A
yellow banner marks it as an illustrative mock, not a live recording.

## fallbacks/first-run.svg

Found in `site/assets/fallbacks/`

Alt text lives in `first-run.alt.txt`. An illustrative terminal mock of
the first run step. A dark terminal window shows `peira run` with the
mock adapter on the trial-demo suite, followed by the summary lines
quoted from the walkthrough doc. A yellow banner marks it as an
illustrative mock, not a live recording.

## fallbacks/report.svg

Found in `site/assets/fallbacks/`

Alt text lives in `report.alt.txt`. An illustrative terminal mock of
the report step. A dark terminal window shows the `peira report`
command writing an HTML report, followed by a command to open it in a
browser. A yellow banner marks it as an illustrative mock, not a live
recording.

## assets/social-preview.svg

Found in repo root `assets/`

A static social preview card for the peira repository. A marble
background carries the word peira in large serif type, the line "the
empirical trial for decision models" beneath it, an ochre rule, and a
footer line reading "adversarial-robustness benchmark for LLM
guardrails, MIT slash CC-BY-4.0". Decorative, no data.
