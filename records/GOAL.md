## Description
David's major GitHub project: an adversarial decision-model robustness benchmark named peira, repo david-engelmann/peira, PyPI name peira claimed. Locked design: MIT license for code plus CC-BY-4.0 for the dataset, Rust core with a PyO3 Python adapter SDK, a 2,500-case v1 dataset (2,000 public + 500 private blind holdout across 10 attack families), a day-one leaderboard of every runnable adapter, and an automation-first operating model maintainable by David alone. v2 expands toward 20+ families x 400+ paired cases plus the sealed blind holdout. The evaluation-science foundation below is the product spec: every metric, family, and protocol decision traces to a verified source or an explicit rejection record.

**Scale rulings (David, 2026-09-28):** every family in scope, no cap; 400/family is a floor, not a ceiling; backward compatibility is dead; v1 defects get fixed, never documented as limitations.

### Statistics and metrics (adopted)
- Keep Wilson 95% intervals (Brown, Cai & DasGupta 2001): the severity-slice tables are exactly the small-n regime.
- McNemar: asymptotic at >=25 discordant pairs, exact mid-p for 10-24 (Fagerland, Lydersen & Laake 2013); keep the <10-discordant withholding floor. MDE at 80% power independently recomputed: n=400/pd=20% -> 6.3pp; n=200/pd=20% -> 8.9pp; resolving 5pp at pd=20% needs n~=630.
- Add log loss / NLL with a documented clipping convention (catches miscalibrated confidence heads; Brier stays). (R-07)
- Decision-curve / net-benefit analysis over confidence thresholds (Vickers & Elkin 2006): the buyer-facing metric, connects thresholds to error/review costs. (R-08)
- Per-run calibration artifact: reliability diagrams, ECE/Brier, selective-risk curves from already-recorded data; rename all public labels to "self-reported confidence"; report abstention rate as a positive signal. (R-11)
- Rankings, not absolute scores, are what replicate (Hardt, *The Emerging Science of Machine Learning Benchmarks*, mlbenchmarks.org, coordinator-verified; PUP hardcover 2026-10-06).
- Rejected: "AUC of ASR" (category error), classwise ECE / F1 / kappa / "flip AUC" (no defined use case), full-suite multi-trial evaluation (triples cost; the R-04 probe answers it at ~1%).
