# dataset v1 (placeholder)

The v1 dataset — 2,500 cases (2,000 public + 500 private holdout, 10 attack
families × 250) — lands here, generated by the dataset pipeline.
This directory will contain:

- `cases.jsonl` — the 2,000 public cases (schema: `schema.json`).
- `trial.jsonl` — the 100-case Peira Trial suite, sampled from v1.
- `manifest.json` — the build manifest: SHA-256 per file plus per-family /
  per-severity counts. Built with
  `peira dataset build-manifest --dir dataset/v1 --version <v>`; verified
  with `peira dataset verify-manifest --dir dataset/v1`. See
  `docs/Dataset.md`.
- `DATASHEET.md` — full datasheet.
- `schema.json` — the frozen case JSON schema.
- `CANARY.txt` — the canary string (added at packaging time; not embedded in v1 case files).

The 500-case private holdout is **never** committed here. It lives
encrypted, maintainer-only; only aggregate metrics are published.

Until v1 lands, `peira run --suite trial-demo` uses the offline demo
fixture in `dataset/trial-demo/`.
